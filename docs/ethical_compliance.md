### 1. Data Usage Compliance

- ✅ The dataset (`dataset.csv`) provided by the HCLTech Career Shaper Programme is used strictly for educational and project evaluation purposes.
- ✅ All dataset usage complies with the source licence and programme guidelines.
- ✅ No additional personal or sensitive data has been collected or used beyond the provided dataset.

### 2. Privacy & Data Protection

- ✅ No personally identifiable information (PII) is collected, stored, or processed without explicit consent.
- ✅ All documents uploaded by users are processed and stored locally on the user's machine.
- ✅ Document content is not shared with any third party except for the OpenAI API when the user explicitly configures an API key for answer generation.
- ✅ The system complies with the Digital Personal Data Protection (DPDP) Act 2023 where applicable.

### 3. AI & Machine Learning Ethics

- ✅ The RAG system includes safeguards against hallucination:
  - Strict system prompts constrain the LLM to answer only from the provided document context.
  - Source documents, chunk text, and relevance scores are displayed alongside every answer.
  - The system explicitly states when an answer cannot be found in the uploaded documents.
- ✅ The system does not generate, endorse, or propagate misinformation.
- ✅ Users are warned that the system should not be used for legal or medical advice without expert review.

### 4. AI Tool Disclosure

- ✅ AI coding assistants were used during the development process for:
  - Code scaffolding and boilerplate generation
  - Documentation drafting
  - Debugging assistance
- ✅ All AI-generated code was reviewed, tested, and customized to meet project requirements.
- ✅ The intellectual work, system design, architecture decisions, and evaluation are the learner's own contribution.

### 5. Intellectual Property

- ✅ All third-party libraries and frameworks used are open source and properly attributed.
- ✅ No proprietary or copyrighted material has been used without permission.
- ✅ References to all academic papers and documentation sources are provided in the project report.

### 6. Responsible Use

- ✅ The system is designed for educational demonstration purposes.
- ✅ Appropriate warnings are included about the limitations of AI-generated answers.
- ✅ The system does not make autonomous decisions; it assists human users in information retrieval.
